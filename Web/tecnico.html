Modelo de datos

GDB_Movilidad — Geodatabase del proyecto

La información se organiza en ocho feature datasets temáticos, cada uno con su propio sistema de referencia de coordenadas, facilitando la gestión topológica y la publicación de servicios web.

Feature Dataset 01
Red Viaria
  • Carreteras (fuente OpenStreetMap)
  • Superficie
  • Pasos Elevados
  • Pasos Subterraneos
  • ND_Madrid — network dataset
Feature Dataset 02
ZBE
  • ZBEDEP Distrito Centro (límite, puntos control, viarios)
  • ZBEDEP Plaza Elíptica (límite, barrios residentes)
  • ZBE General (con y sin pegatina)
  • ZBE Merge Total · ZBE Pegatina Merge
  • Cámaras de control · Foto-rojos
Feature Dataset 03
Estacionamientos
  • SER Azul / Naranja / Verde / Rojo (polígono + punto)
  • Aparcamiento Alta Rotación
  • Aparcamientos (Garajes)
  • Aparcamientos Minusválido
Feature Dataset 04
Seguridad Vial
  • Radares de Velocidad (fijos)
Feature Dataset 05
Servicios
  • Gasolineras
  • Recarga Vehículos Eléctricos
  • Elementos de Interés (turismo y cultura)
Feature Dataset 06
Capas_Accesibilidad_Aparcamiento
  • Aparcamientos (merge total)
  • Aparcamientos dentro de ZBE
  • Sin Aparcamientos dentro de ZBE
  • Zona de estudio de Aparcamiento
  • Ráster Densidad Kernel
Feature Dataset 07
Rutas_Punto_A_Punto_B
  • Rutas calculadas
  • Puntos de origen y destino
Automatización

ModelBuilder y Python (ArcPy)

Todos los procesos de construcción y análisis se automatizan mediante dos modelos ModelBuilder y dos notebooks de Python, garantizando reproducibilidad y escalabilidad del proyecto.

01
ModelBuilder · Modelo 1
Infraestructura de datos y distribución de capas

Genera la estructura completa de la geodatabase e itera sobre las capas en bruto distribuyéndolas automáticamente en los ocho feature datasets correspondientes.

1
Create File Geodatabase → GDB_Movilidad
2
Create Feature Dataset × 5 datasets temáticos
3
Iterate Feature Classes sobre datos raw
4
Project + Add Field + Calculate Field
5
Select Layer By Attributes + If row Count → Copy Features al dataset correcto
02
ModelBuilder · Modelo 2
Análisis espacial de cobertura de estacionamientos

Identifica las áreas con y sin cobertura de estacionamiento dentro del ámbito ZBE y genera un ráster de densidad Kernel para visualizar la concentración de servicios.

1
Merge → Servicios_Total (todas las capas parking)
2
Buffer → Buffer_Servicios
3
Dissolve → elimina solapamientos
4
Clip por ZBE · Minimum Bounding Geometry
5
Erase → zonas sin cobertura · Kernel Density → ráster
Python / ArcPy · Notebook 1
Construcción de la red viaria

Automatiza la preparación de la capa de carreteras y la creación del network dataset ND_Madrid, desde la asignación de velocidades por fclass hasta la configuración del modelo de elevación por campos.

UpdateCursor velocidades CalculateGeometryAttributes Jerarquía vial (4 niveles) Split Superficie / Elevados / Subterráneos Integrate topológico CreateNetworkDataset
Python / ArcPy · Notebook 2
Análisis de ruta con evaluación ZBE

Calcula la ruta óptima entre origen y destino, evalúa si es válida para la etiqueta ambiental del vehículo (0, ECO, C, B o SIN etiqueta) y genera automáticamente una ruta alternativa con Polygon Barriers si la ruta no es válida.

MakeRouteAnalysisLayer Polygon Barriers ZBE Intersect validación Color_ZBE VERDE / ROJO Ruta alternativa automática 5 etiquetas DGT
Gestión de usuarios y grupos

Perfiles de usuario en ArcGIS Online

La organización de ArcGIS Online se ha estructurado en dos grupos que reflejan los perfiles definidos en el proyecto, controlando el acceso a los contenidos y las aplicaciones de cada rol.

🔬
Técnicos GIS, Gestores y Servicios de Emergencia

Profesionales con formación en SIG y gestión territorial, así como cuerpos de seguridad y emergencia que operan sobre el terreno. Acceso completo a todos los servicios, capas editables y herramientas de análisis. Tienen permisos para publicar y modificar contenidos en el portal.

ArcGIS Pro Experience Builder Field Maps
  • Actualización y validación de datos en campo
  • Gestión del ciclo de vida de incidencias (Abierta → En revisión → Resuelta)
  • Seguimiento del estado de la red viaria y sus servicios asociados
  • Publicación y modificación de servicios web en ArcGIS Online
🧭
Público General

Ciudadanos y turistas sin conocimientos técnicos GIS. Acceden a través de aplicaciones públicas diseñadas para ser autoexplicativas. No tienen permisos de edición sobre los datos de infraestructura.

StoryMaps Experience Builder QuickCapture
  • Planificar rutas y consultar restricciones ZBE según etiqueta DGT
  • Localizar gasolineras, puntos de recarga y aparcamientos en ruta
  • Descubrir puntos de interés turístico accesibles desde el itinerario
  • Reportar incidencias de tráfico con un único toque (QuickCapture)
  • Acceder a servicios públicos abiertos del proyecto
